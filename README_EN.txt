BAD CHEESE - THAI SUBTITLES MOD
Version 1.1.0

Thai translation by: ดอกตีนเป็ดหอมแฮง
Facebook Page: ดอกตีนเป็ดหอมแฮง

============================================================
ABOUT
============================================================
This mod adds Thai subtitles/text for Bad Cheese
(452 translated text entries) and shows the translator credit
in the top-right corner of the main menu.

Supported stores:
- Steam
- Epic Games Store

Details:
- Sarabun for dialogue and general UI
- Itim for Pause menu / objective / credits headings
- wqy-microhei is replaced with Sarabun Bold for bolder UI text
- The in-game language name is changed to "ไทย" (Thai)
- The main menu shows, at the top right:
    v1.02.00 05.09.2025 18-36
    แปลไทยโดย ดอกตีนเป็ดหอมแฮง
- No original game files are modified; the mod only adds files to
  BadCheese\Content\Paks

Installed files (4):
- Thai_P.pak        translations + fonts
- ThaiMenu_P.pak    loader for the main menu patch
- ThaiMenu_P.ucas   main menu patch data
- ThaiMenu_P.utoc   main menu patch index

============================================================
REQUIREMENTS
============================================================
- Bad Cheese on PC (Steam or Epic Games Store)
- Windows 10 or 11
- The game must be closed before installing

============================================================
INSTALL
============================================================
1. Extract the ZIP file.
2. Close Bad Cheese completely.
3. Run install.bat.
4. The installer automatically finds the game on Steam and on
   Epic Games, and shows the folder it detected.
5. If Windows asks for permission, choose Yes
   (required when the game is in Program Files).
   If SmartScreen warns, choose More info > Run anyway
   (the installer is a plain-text script you can inspect).
6. Open the game, go to Settings > Language, and select "ไทย".
7. If Thai does not appear, restart the game.

If the installer cannot find the game, run install.bat and enter the
game folder manually, for example:
  Steam: D:\SteamLibrary\steamapps\common\Bad Cheese
  Epic:  D:\Epic Games\BadCheeseMA8aG
The correct folder is the one containing BadCheese.exe.

============================================================
UNINSTALL
============================================================
1. Close the game.
2. Run uninstall.bat.
3. The script removes all 4 mod files, plus the backups that the
   installer made from an older version of this mod.
4. The game returns to English. (If a different Thai_P.pak was in the
   folder before the mod, that file is put back.)

============================================================
NOTES
============================================================
- wqy-microhei is replaced with Sarabun Bold. If you switch to
  Chinese, Japanese, Korean, or Russian, some glyphs may be missing.
- If the game updates, the ThaiMenu_P files may stop working.
  Delete ThaiMenu_P.* and wait for a mod update.
  The main translation in Thai_P.pak keeps working.
