============================================================
รองรับทั้ง 2 ร้าน
============================================================
- Steam
- Epic Games Store

ตัวติดตั้งตัวเดียวตรวจหาเกมให้อัตโนมัติทั้งสองร้าน
มอดนี้เพิ่มคำแปลภาษาไทย 452 รายการ
และแสดงเครดิตผู้แปลที่มุมขวาบนของเมนูหลัก

============================================================
สิ่งที่ต้องมี
============================================================
- เกม Bad Cheese เวอร์ชัน PC (Steam หรือ Epic Games Store)
- Windows 10 หรือ 11
- ปิดเกมก่อนติดตั้ง

============================================================
วิธีติดตั้ง
============================================================
1. แตกไฟล์ ZIP นี้ไว้ที่ใดก็ได้
2. ปิดเกม Bad Cheese ให้สนิท
3. ดับเบิลคลิก install.bat
4. ตัวติดตั้งจะค้นหาเกมทั้ง Steam และ Epic Games ให้อัตโนมัติ
   แล้วแสดงโฟลเดอร์เกมที่พบให้ตรวจสอบก่อนติดตั้ง
5. ถ้า Windows ถามสิทธิ์ ให้เลือก Yes
   (จำเป็นเมื่อเกมติดตั้งอยู่ใน Program Files)
   หาก SmartScreen เตือน ให้เลือก More info > Run anyway
   (สคริปต์เป็นไฟล์ข้อความธรรมดา เปิดดูโค้ดได้)
6. เปิดเกม แล้วไปที่ Settings > Language > เลือก "ไทย"
7. ถ้าไม่เห็นภาษาไทย ให้ปิดเกมแล้วเปิดใหม่

ไฟล์ที่ตัวติดตั้งจะเพิ่มในโฟลเดอร์ Content\Paks (4 ไฟล์):
- Thai_P.pak        คำแปล + ฟอนต์
- ThaiMenu_P.pak    ตัวโหลดแพตช์เมนูหลัก
- ThaiMenu_P.ucas   ข้อมูลเมนูหลัก
- ThaiMenu_P.utoc   ดัชนีเมนูหลัก

============================================================
หากตัวติดตั้งหาเกมไม่พบ
============================================================
1. ดับเบิลคลิก install.bat อีกครั้ง
2. เมื่อโปรแกรมถาม ให้พิมพ์ path ของโฟลเดอร์เกม
   ตัวอย่าง Steam:  D:\SteamLibrary\steamapps\common\Bad Cheese
   ตัวอย่าง Epic:   D:\Epic Games\BadCheeseMA8aG
3. โฟลเดอร์ที่ถูกต้องคือโฟลเดอร์ที่มีไฟล์ BadCheese.exe

============================================================
วิธีถอนมอด
============================================================
1. ปิดเกม
2. ดับเบิลคลิก uninstall.bat
3. สคริปต์จะลบไฟล์ของมอดทั้ง 4 ไฟล์
   พร้อมไฟล์สำรองที่ตัวติดตั้งสร้างไว้ให้เอง
4. เกมจะกลับไปเป็นภาษาอังกฤษตามเดิม
   (ถ้าในโฟลเดอร์เคยมี Thai_P.pak ของมอดอื่นอยู่ก่อน
   ตัวถอนจะคืนไฟล์นั้นกลับให้)

============================================================
หมายเหตุสำคัญ
============================================================
- มอดนี้เป็นงานแฟนทรานสเลชัน ไม่ใช่ทางการ
  และไม่ได้เกี่ยวข้องกับผู้พัฒนาเกม
- ห้ามนำไปขาย สามารถแชร์ต่อได้
  โดยให้เครดิตผู้แปลและเพจ
- มอดนี้แทนที่ wqy-microhei ด้วย Sarabun Bold
  หากสลับไปภาษาจีน ญี่ปุ่น เกาหลี หรือรัสเซีย
  ตัวอักษรของภาษานั้นอาจแสดงไม่ครบ
- หากเกมอัปเดตเวอร์ชันใหม่ ไฟล์ ThaiMenu_P อาจใช้ไม่ได้
  ให้ลบ ThaiMenu_P.* ออกก่อน แล้วรอตัวมอดเวอร์ชันใหม่
  (คำแปลหลักใน Thai_P.pak ยังใช้งานได้ปกติ)
